🚕 Cabbie AI Assistant

Cabbie AI is a built-in assistant (built by Chris Hinojosa) that can answer questions about this workspace — due dates, posting schedules, labels, cards — and make changes for you when asked. It only knows about this app and won't answer unrelated questions. It's powered by OpenRouter using the free poolside/laguna-s-2.1:free model.

Get a free key at openrouter.ai/keys. The key is stored with the rest of this workspace's settings, the same way the Monday.com token above is.
